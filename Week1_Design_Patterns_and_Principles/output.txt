=== Observer Pattern ===
=== Observer Pattern Example ===

Observer registered for GOOGL
Observer registered for GOOGL
Observer registered for GOOGL

GOOGL price changed: $2800.0 -> $2850.5
[StockTracker - Mobile] GOOGL is now $2850.5
[StockDashboard - Web] GOOGL is now $2850.5
[InvestorApp - Mobile] GOOGL is now $2850.5

GOOGL price changed: $2850.5 -> $2900.75
[StockTracker - Mobile] GOOGL is now $2900.75
[StockDashboard - Web] GOOGL is now $2900.75
[InvestorApp - Mobile] GOOGL is now $2900.75
Observer deregistered from GOOGL

GOOGL price changed: $2900.75 -> $2875.0
[StockTracker - Mobile] GOOGL is now $2875.0
[StockDashboard - Web] GOOGL is now $2875.0
